# Manu o te nūnaʻa

Un jeu éducatif pour apprendre à gouverner Motu Nui, une île fictive du Pacifique : deux mandats, huit années, 88 situations inspirées de l'histoire réelle, des référendums, le courrier des citoyens et un lexique de 145 mots du gouvernement.

Jouer : ouvrez `index.html`, ou la page GitHub Pages du dépôt.

- Fonctionne sur téléphone et ordinateur ; s'installe sur l'écran d'accueil (« Ajouter à l'écran d'accueil »).
- Fonctionne hors ligne après la première visite.
- La partie est enregistrée sur l'appareil (aucune donnée envoyée).
